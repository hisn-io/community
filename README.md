# Hisn.io community

Questions, help and ideas for [Hisn.io](https://hisn.io) live in [Discussions](https://github.com/hisn-io/community/discussions).

- **Q&A:** ask how to do something with Hisn.io, the `hisn` CLI or `hisn.toml`.
- **Ideas:** suggest a feature or an improvement.
- **Show and tell:** share what you have built.

This is the support channel for the Starter plan, answered on a best effort basis. Pro, Business and Enterprise customers have email support with published response times; see [the plans](https://hisn.io/plans).

Documentation: [docs.hisn.io](https://docs.hisn.io). To report a security issue, do not post here: see [the security policy](https://hisn.io/.well-known/security.txt). To report abuse: abuse@hisn.io.
